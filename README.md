# TD Edge V5

Browser-only Streamlit NFL anytime-touchdown research dashboard. See ../README.txt for deployment and API key setup. New features: Upcoming games & top 3 estimated EV selections per matchup, on-demand NFL anytime-TD YES bookmaker quotes from The Odds API, best available price per player/event, research screening filters, and historical odds ROI upload. Existing chronological model validation and nested model selection retained.

No API key or historical bookmaker data is included. Do not commit secrets to GitHub. Odds API event-level props cost usage credits. The app is research-only; EV is model-implied and unproven.
